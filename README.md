# ParcelFlow test assets demo

Synthetic test catalogue, static test definitions and supporting documentation,
extracted from the ParcelFlow demonstration application at `d751980ef8d381a43a159b56ac7cf2c568990270`.

This is a **static-discovery asset snapshot**, not an independently executable
application or test suite. Application implementation, configuration, runtime
snapshots, dependency packaging and server setup are deliberately not included.
References and imports in these files do not grant access to additional sources.

Original paths and catalogue IDs are retained. See `source-manifest.json` for
origin and content hashes. Snapshot origin is not proof of compatibility with
another application version. No application tests were executed for extraction.
Existing stale references are retained rather than silently repaired.

The HTML document is a dual-purpose demo UI/manual-step target. The Postman
collection and JavaScript file are inspection assets; their inclusion does not
establish server availability or successful execution.

All data is for demonstration. No client data or enterprise agent configuration
belongs in this repository. Application and test-source identities must be
specified independently by consumers.

## Snapshot derivation

Selected descriptive docstrings and documentation wording have been normalized.
Executable statements, assertions, selectors and the catalogue are unchanged.
Asset entries in `source-manifest.json` distinguish original content hashes from
this derivative snapshot's hashes. Files marked as transformed are not
byte-identical mirrors of their origin. Application compatibility remains unverified.
